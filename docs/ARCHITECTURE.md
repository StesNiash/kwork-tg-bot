# Архитектура

```text
Telegram getUpdates
        │
        ▼
LeadBot.handle_update
        │
        ├── state: name → phone → comment
        ├── normalize_phone
        ├── LeadStore (SQLite)
        └── WebhookSink (Google Sheets, optional)
```

## Решения

### SQLite — источник истины

Webhook может быть недоступен. Заявка сначала сохраняется локально, поэтому сбой Google Sheets не приводит к потере лида.

### Тонкий транспорт

`TelegramTransport` изолирует HTTP-вызовы. В тестах и демо используется фейковый транспорт, поэтому сценарий диалога проверяется без токена и сети.

### Webhook с секретом

Секрет передаётся в теле запроса и заголовке. Apps Script проверяет его до записи строки в таблицу.

### Состояние в памяти

Для простого бота состояние диалога хранится в словаре. Это ограничение явно описано: после рестарта незавершённая заявка начинается заново.

## Границы

- Нет очереди повторной отправки в Sheets.
- Нет ролей и админ-панели.
- Нет вложений.
- Нет платежей и рассылок.
