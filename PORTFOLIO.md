# Портфолио: Telegram-бот заявок

## Задача

Собрать заявки из Telegram без ручного переноса и не потерять данные, если внешняя таблица временно недоступна.

## Решение

- пошаговый диалог: имя, телефон, комментарий;
- валидация и нормализация телефона;
- SQLite как основное хранилище;
- CSV-экспорт;
- опциональный webhook в Google Sheets;
- ошибки webhook не откатывают заявку.

## Результат

- 6 тестов проходят;
- демо: два диалога, 2 заявки, 16 сообщений;
- `demo/leads.csv`, `demo/index.html`, `screenshots/demo.png`;
- нет токенов и клиентских данных.

## Что показывает

- работу с Telegram Bot API без тяжёлого фреймворка;
- аккуратную state machine;
- выбор SQLite как надёжного локального источника;
- понимание, что внешняя интеграция может падать.

## Стек

Python 3.10+, Telegram Bot API, SQLite, urllib, unittest.
